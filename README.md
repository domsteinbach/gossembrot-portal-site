# Gossembrot-Portal

A project of the Swiss Nationalfonds (2021–2025); Lead: Prof. Dr. Michael Stolz (University of Bern).

The main projects page is deployed at https://gossembrot.unibe.ch/gossembrot-portal. This is the build for a static version available at: https://domsteinbach.github.io/gossembrot-portal-site/. This static version is built and deployed automatically on every push to the main branch via github actions (.github/workflows/deploy-gh-pages.yml)
